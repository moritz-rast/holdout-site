# Holdout pre-launch website

A one-page static website for Holdout, a home fitness challenge app in development.

Live: https://moritz-rast.github.io/holdout-site/

Plain HTML, CSS and one small script, with no build step, cookies or external requests. To change something, edit the files and push to `main`; GitHub Pages publishes the new version.

The font (Inter, the same as in the app) is self-hosted in `assets/fonts/` under the SIL Open Font License; the licence is next to it.
