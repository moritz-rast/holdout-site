# Holdout pre-launch website

A one-page static website for Holdout, a home fitness challenge app in development.

Live: https://moritz-rast.github.io/holdout-site/

Plain HTML and CSS, with no build step, JavaScript, cookies or external requests. To change something, edit the files and push to `main`; GitHub Pages publishes the new version.

The fonts (Space Grotesk and DM Sans) are self-hosted in `assets/fonts/` under the SIL Open Font License; the licences are next to them.
